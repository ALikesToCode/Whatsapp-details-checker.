# WhatsApp Wrapped UI

Runs a gamified “profile + badges” view for members extracted from WhatsApp chat exports.

## Dev

```bash
pnpm dev
```

## Data sources

- Upload one or more WhatsApp `.txt` exports in the UI (processed locally in the browser), or
- Put a precomputed file at `web/public/data/members.json` (generated by `../analyze_chat.py`).
